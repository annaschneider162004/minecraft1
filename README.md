# Minecraft Architect — Java 1.20.1

Forge mod MVP for Minecraft Java 1.20.1 (Forge 47.x). It creates small deterministic structures from templates and places them gradually on the server.

## Requirements

- Java 17
- Minecraft Java 1.20.1
- Forge 47.x
- Gradle 8.x or the Gradle wrapper generated by Forge MDK

## Build

```bash
gradle build
```

The jar is created in `build/libs/`. Put it in the `mods` directory of a Forge 1.20.1 installation.

For a development client/server, run `gradle runClient` or `gradle runServer`.

## Commands

- `/architect help`
- `/architect build house`
- `/architect build castle`
- `/architect build village`
- `/architect rotate 90` — builds a rotated house in the current MVP
- `/architect undo` — removes the last completed build for the player

Builds are deliberately small and are placed 64 blocks per server tick. This makes the progress visible and avoids a single large blocking operation.

## AI integration roadmap

The current version uses local templates and does not require an API key or Internet connection. The next step is to add an `ArchitectProvider` interface that converts a prompt into a validated blueprint JSON document. A remote LLM provider should run outside the Minecraft server or behind an explicit configuration, with strict size/block validation before placement.

## Limitations

- The current `rotate` command demonstrates rotation by building a rotated house; persistent rotation selection and mirror operations are planned.
- Save/load and arbitrary JSON blueprints are planned for the next iteration.
- Undo tracks the positions from the most recent build and restores them to air; do not use it when other players are editing the same area.
